You are playing a series of labyrinths. Your task is to solve all labyrinths using the minimal number of moves.

You will be given a description of each labyrinth. Please read each description carefully.

For the first few labyrinths, you will be given an open map with your position shown on it. These are tutorial labyrinths designed to help you understand the mechanics.

For the remaining labyrinths, the map will be hidden. You will only be given your initial position in the labyrinth description.
