# Supporting materials for “Improving Environment-Agnostic Coding Agents: The Role of Scaffolding”

**Paper:** [arXiv:2610.22289](https://arxiv.org/abs/2610.22289)

## Code and agents

- [EnvTraverse v0.1](../../envtraverse_v0.1/) — the exact framework version used in
  the paper. Run [Baseline](../../envtraverse_v0.1/src/agents/agent_v1/),
  [Stop-and-report](../../envtraverse_v0.1/src/agents/agent_v1_01_wstop/), and
  [Controlled_RESET](../../envtraverse_v0.1/src/agents/test_arc3_agent_v1_02_wstop_wreset/)
  through this framework. See its [README](../../envtraverse_v0.1/README.md) for
  setup and usage.
- [`twma_v1.61`](twma_v1.61/) — the ARC-AGI-3-specific agent `twma_v1.6` from
  [our previous article](https://github.com/astroseger/arc-3-agents-baseline1/tree/main/papers/paper02),
  with an updated Codex version.
