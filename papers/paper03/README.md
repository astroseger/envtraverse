## Code and agents

[`EnvTraverse v0.1`](../../envtraverse_v0.1/) is the exact framework version used in
the paper. See its [README](../../envtraverse_v0.1/README.md) for setup and usage.

[Baseline (`agent_v1`)](../../envtraverse_v0.1/src/agents/agent_v1/),
[Stop-and-report (`agent_v1_01_wstop`)](../../envtraverse_v0.1/src/agents/agent_v1_01_wstop/),
and [Controlled_RESET (`test_arc3_agent_v1_02_wstop_wreset`)](../../envtraverse_v0.1/src/agents/test_arc3_agent_v1_02_wstop_wreset/)
can be run through EnvTraverse.

The ARC-AGI-3-specific agent [`twma_v1.61`](twma_v1.61/) is `twma_v1.6` from
[our previous article](https://github.com/astroseger/arc-3-agents-baseline1/tree/main/papers/paper02),
with an updated Codex version.
