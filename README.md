# EnvTraverse

This repository is the project page for our experiments with environment-agnostic
agents using our experimental framework, EnvTraverse.

## Framework

EnvTraverse connects independently implemented agents and environments through a
common interaction contract: environment descriptions, JSON actions, and observation
files. This lets us run and evaluate the same agent unchanged across different
environments.

See the [framework README](envtraverse_v0.1/README.md) for setup and usage.
